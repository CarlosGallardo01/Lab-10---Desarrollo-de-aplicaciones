# Gestión de Productos - Laboratorio 10

Prototipo funcional de una interfaz web para gestionar el catálogo de una empresa comercial, desarrollado con React, Vite, Tailwind CSS y shadcn/ui. No requiere conexión a un backend (los datos iniciales son simulados en memoria).

## Tecnologías utilizadas
- **Frontend:** React (Hooks funcionales, `useState`)
- **Build Tool:** Vite
- **Estilos:** Tailwind CSS
- **Componentes UI:** shadcn/ui (Button, Input, Label, Card, Table)
